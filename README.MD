# Mobile Application for Disaster Preparedness and Response
This repository is for a project involving the development of a mobile application for disaster preparedness and response in Indonesia.

## Notes
### Code that I did not write myself are marked accordingly. Otherwise, I wrote the code myself.
### I intentionally removed translation files (languages/en and languages/id) from the commit history, because the previous version might have contained content that were not pharaphrased enough or not referenced/attributed.

## Tech Stack
- This project uses Expo and React Native to develop the mobile application. 
- Supabase is used for the database.
- Cloudflare Workers are used to regularly call API endpoints and add new disaster data to the database.

## Acknowledgement
### Disaster Data Sources
The mobile application uses disaster data from BMKG (Badan Meteorologi, Klimatologi dan Geofisika) and PetaBencana.id (proper attribution texts are shown in the app). The links to the APIs' documentation pages are as follows:
- https://data.bmkg.go.id/gempabumi/
- https://docs.petabencana.id/

### Indonesian Admin Boundaries Data Sources
The mobile application uses Indonesian admin boundaries data from Badan Pusat Statistik Indonesia (propoer attribution texts are shown in the app).

### Map
This mobile application uses OpenFreeMap (https://openfreemap.org/) for the maps.

### AI-generated Visual Assets
This mobile application uses some visual assets (avatars, badges, level badges) that are AI-generated using GPT-5.4 mini accessed through Duck.ai (https://duck.ai).
