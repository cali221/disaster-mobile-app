## Source of the Images
The images in this directory are AI-generated. They were originally in .jpeg format after creation. Then I removed the background of the images using an online tool and downloaded the images as PNG format before adding them to this directory. The chat used to generate the images can be seen in the chat.txt file in this directory. The model in the chat was GPT-5.4 mini, with GPT Image 2 labels being shown on top of the generated images on the DuckDuckGo browser where the generation took place, indicating it was likely the image generation model used. The images are currently stored in Supabase and accessed through Supabase, but they are also stored in this directory for documentation and version control purposes.
